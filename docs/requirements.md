# 要求仕様書

## プロジェクト概要

Escape from Tarkov のタスク進捗管理サイト。プレイヤーが自分のタスク進行度を把握するためのツール。

## 解決したい課題

- タルコフのタスクを進めているが、全体の何％完了しているかわからない
- 各トレーダーごとの進捗状況を把握したい

## 機能要件

### 1. タスク一覧画面（メイン機能）

- トレーダー別にタスクを一覧表示
- 各タスクにチェックボックスを表示
- タスクをクリック/チェックで「クリア済み」としてマーク
- クリア済みタスクの視覚的な区別（取り消し線、色変更など）

### 2. 進捗ダッシュボード（メイン機能）

- **全体進捗率**: クリア済みタスク数 / 全タスク数（%表示）
- **トレーダー別進捗率**: 各トレーダーごとの進捗率
- プログレスバーによる視覚化
- 残りタスク数の表示

### 3. データ永続化

- クリア状態をローカルストレージに保存（認証不要）
- ブラウザを閉じても進捗が保持される

### 4. 必要アイテム一覧（サブ機能）

- 未完了タスクで必要なアイテムを一覧表示
- アイテムごとに必要数を集計
- どのタスクで使うかを表示
- 「Found in Raid」が必要かどうかを表示

### 5. フィルタリング・検索（補助機能）

- クリア済み / 未クリアでフィルタ
- タスク名で検索
- トレーダーでフィルタ

## 非機能要件

- ユーザー認証なし
- レスポンシブデザイン（PC・モバイル対応）
- 日本語対応

## データモデル

### タスク (Task)

| フィールド | 型 | 説明 |
|-----------|------|------|
| id | string | 一意識別子 |
| name | string | タスク名 |
| trader_id | string | トレーダーID |
| required_level | int | 必要レベル |

### トレーダー (Trader)

| フィールド | 型 | 説明 |
|-----------|------|------|
| id | string | 一意識別子 |
| name | string | トレーダー名 |

### アイテム (Item)

| フィールド | 型 | 説明 |
|-----------|------|------|
| id | string | 一意識別子 |
| name | string | アイテム名 |
| image_url | string | アイテム画像 |

### タスク目標 (TaskObjective)

| フィールド | 型 | 説明 |
|-----------|------|------|
| id | string | 一意識別子 |
| task_id | string | タスクID |
| type | string | 目標タイプ（giveItem, findItem等） |
| item_id | string | 必要アイテムID |
| count | int | 必要数 |
| found_in_raid | bool | FiR必須かどうか |

### 進捗（フロントエンドのみ・localStorage）

| キー | 型 | 説明 |
|-----|------|------|
| completedTasks | string[] | クリア済みタスクIDの配列 |

## 技術スタック

- フロントエンド: Next.js (TypeScript)
- バックエンド: Python (FastAPI)
- データベース: PostgreSQL
- インフラ: Docker / Docker Compose

## データソース

タスク・トレーダーデータは [Tarkov.dev GraphQL API](https://api.tarkov.dev/) から取得。

**エンドポイント**: `https://api.tarkov.dev/graphql`

**タスク取得クエリ例**:
```graphql
{
  tasks {
    id
    name
    trader {
      id
      name
    }
    minPlayerLevel
    map {
      name
    }
  }
}
```
