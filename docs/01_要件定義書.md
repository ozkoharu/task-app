作成日: 2026-01-25
バージョン: 1.0

## 1. ドキュメント概要

### 1.1 目的

本ドキュメントは、Escape from Tarkov タスク進捗管理サイトのMVP（Minimum Viable Product）における要件を定義する。プレイヤーが自身のタスク進行度を把握し、効率的にゲームを進めるための支援ツールとして開発する。

## 2. MVPスコープ定義

### 2.1 MVP機能一覧

| 要件ID | 機能名 | MVP対象 | 優先度 |
|--------|-------|---------|--------|
| F-001 | タスク一覧表示 | 対象 | 必須 |
| F-002 | タスク完了チェック | 対象 | 必須 |
| F-003 | 進捗ダッシュボード | 対象 | 必須 |
| F-004 | ローカルストレージ保存 | 対象 | 必須 |
| F-005 | フィルタリング・検索 | 対象 | 必須 |
| F-006 | 必要アイテム一覧 | 対象外 | Phase2 |
| F-007 | タスク依存関係表示 | 対象外 | Phase2 |
| F-008 | マップ別タスク表示 | 対象外 | Phase2 |
| F-009 | 進捗データエクスポート | 対象外 | Phase2 |
| F-010 | ユーザー認証・同期 | 対象外 | Phase2 |

### 2.2 MVP表示機能

| 機能 | MVP対象 | 説明 |
|------|---------|------|
| 全体進捗率表示 | 対象 | 全タスクに対する完了率をプログレスバーで表示 |
| トレーダー別進捗率 | 対象 | 各トレーダーごとの進捗率を個別表示 |
| タスク一覧 | 対象 | チェックボックス付きのタスクリスト |
| 残りタスク数 | 対象 | 未完了タスクの件数表示 |

### 2.3 除外事項（Phase2以降）

- **必要アイテム一覧（F-006）**: 未完了タスクで必要なアイテムの集計表示
- **タスク依存関係表示（F-007）**: 前提タスクのツリー表示
- **マップ別タスク表示（F-008）**: マップごとのタスクグルーピング
- **進捗データエクスポート（F-009）**: JSON/CSV形式でのダウンロード機能
- **ユーザー認証・同期（F-010）**: アカウント連携によるクロスデバイス同期

## 3. 機能要件詳細

### 3.1 F-001: タスク一覧表示

#### 3.1.1 概要

Tarkov.dev APIから取得したタスクデータをトレーダー別に一覧表示する機能。

#### 3.1.2 機能詳細

| 項目 | 仕様 |
|------|------|
| データソース | Tarkov.dev GraphQL API |
| 表示形式 | トレーダー別グルーピング |
| ソート | トレーダー内で必要レベル順 |
| 表示項目 | タスク名、必要レベル、完了状態 |

#### 3.1.3 ユースケース

**UC-001: タスク一覧を閲覧する**

| 項目 | 内容 |
|------|------|
| アクター | プレイヤー |
| 事前条件 | なし |
| 基本フロー | 1. サイトにアクセス<br>2. タスク一覧画面が表示される<br>3. トレーダー別にタスクが表示される<br>4. 各タスクの完了状態が確認できる |
| 事後条件 | タスク一覧が正常に表示される |
| 代替フロー | API取得失敗時はエラーメッセージを表示 |

#### 3.1.4 UI要件

- トレーダーアイコンまたは名前による視覚的な区別
- タスク名の日本語/英語表示対応
- 完了済みタスクの視覚的区別（取り消し線、グレーアウト等）
- スクロール可能なリスト表示

### 3.2 F-002: タスク完了チェック

#### 3.2.1 概要

各タスクに対して完了/未完了の状態をトグルする機能。

#### 3.2.2 機能詳細

| 項目 | 仕様 |
|------|------|
| 操作方法 | チェックボックスのクリック |
| 状態 | 完了 / 未完了（2値） |
| 反映 | 即時反映（ページリロード不要） |
| 保存 | ローカルストレージに自動保存 |

#### 3.2.3 ユースケース

**UC-002: タスクを完了としてマークする**

| 項目 | 内容 |
|------|------|
| アクター | プレイヤー |
| 事前条件 | タスク一覧が表示されている |
| 基本フロー | 1. 完了したタスクのチェックボックスをクリック<br>2. タスクが完了状態になる<br>3. 進捗率が更新される<br>4. ローカルストレージに保存される |
| 事後条件 | タスクが完了状態として保存される |
| 代替フロー | 再度クリックで未完了に戻す |

#### 3.2.4 UI要件

- クリック可能なチェックボックス
- 状態変更時のビジュアルフィードバック
- 完了タスクの視覚的区別

### 3.3 F-003: 進捗ダッシュボード

#### 3.3.1 概要

全体およびトレーダー別のタスク進捗率を視覚的に表示するダッシュボード機能。

#### 3.3.2 表示項目

| 表示項目 | 説明 |
|---------|------|
| 全体進捗率 | クリア済みタスク数 / 全タスク数（%表示） |
| トレーダー別進捗率 | 各トレーダーごとの完了率 |
| 残りタスク数 | 未完了タスクの総数 |
| 完了タスク数 | 完了済みタスクの総数 |

#### 3.3.3 ユースケース

**UC-003: 進捗状況を確認する**

| 項目 | 内容 |
|------|------|
| アクター | プレイヤー |
| 事前条件 | タスク一覧が表示されている |
| 基本フロー | 1. ダッシュボードエリアを確認<br>2. 全体進捗率を確認<br>3. トレーダー別の進捗率を確認 |
| 事後条件 | 現在の進捗状況が把握できる |

#### 3.3.4 UI要件

- プログレスバーによる視覚化
- パーセンテージの数値表示
- タスク数の表示（例: 180/400）
- トレーダーアイコンまたは名前の表示

### 3.4 F-004: ローカルストレージ保存

#### 3.4.1 概要

タスクの完了状態をブラウザのローカルストレージに保存し、永続化する機能。

#### 3.4.2 技術仕様

| 項目 | 仕様 |
|------|------|
| ストレージ | localStorage |
| データ形式 | JSON |
| キー名 | completedTasks |
| 値 | 完了済みタスクIDの配列 |

#### 3.4.3 データ形式

```json
{
  "completedTasks": [
    "5c51aac186f77432ea65c552",
    "5936d90786f7742b1420ba5b",
    "5936da9e86f7742d65037edf"
  ]
}
```

#### 3.4.4 ユースケース

**UC-004: 進捗データを永続化する**

| 項目 | 内容 |
|------|------|
| アクター | システム |
| 事前条件 | タスクの完了状態が変更された |
| 基本フロー | 1. 完了状態の変更を検知<br>2. ローカルストレージに保存<br>3. 次回アクセス時に復元 |
| 事後条件 | ブラウザを閉じても進捗が保持される |

### 3.5 F-005: フィルタリング・検索

#### 3.5.1 概要

タスク一覧をフィルタリング・検索する機能。

#### 3.5.2 フィルタ項目

| フィルタ項目 | 説明 |
|-------------|------|
| 完了状態 | クリア済み / 未クリア / すべて |
| トレーダー | 特定のトレーダーのタスクのみ表示 |
| テキスト検索 | タスク名での部分一致検索 |

#### 3.5.3 ユースケース

**UC-005: タスクを検索・フィルタする**

| 項目 | 内容 |
|------|------|
| アクター | プレイヤー |
| 事前条件 | タスク一覧が表示されている |
| 基本フロー | 1. フィルタ条件を選択/入力<br>2. 条件に合致するタスクのみ表示<br>3. 結果件数を確認 |
| 事後条件 | フィルタ結果が表示される |

#### 3.5.4 UI要件

- トレーダー選択ドロップダウン
- 完了状態トグル/ボタン
- テキスト検索入力フィールド
- フィルタ結果件数の表示
- フィルタクリアボタン

## 4. 非機能要件

### 4.1 性能要件

| 項目 | 要件 | 測定方法 |
|------|------|---------|
| 初期表示速度 | 3秒以内にタスク一覧表示 | Lighthouse測定 |
| 操作レスポンス | チェック操作から100ms以内に反映 | ブラウザDevTools |
| API応答 | 500ms以内にレスポンス | サーバーログ |
| 同時接続数 | 100ユーザー（MVP段階） | 負荷テスト |

### 4.2 ユーザビリティ要件

| 項目 | 要件 |
|------|------|
| レスポンシブ対応 | PC・タブレット・モバイル対応 |
| 言語 | 日本語UI |
| 認証 | 不要（匿名利用可能） |
| アクセシビリティ | キーボード操作対応 |

### 4.3 拡張性要件

| 項目 | 要件 |
|------|------|
| APIバージョン | Tarkov.dev APIの変更に追従可能 |
| データモデル | 新規フィールド追加に対応 |
| 多言語化 | i18n対応の基盤準備 |
| 認証追加 | Phase2での認証機能追加を考慮 |

### 4.4 保守性要件

| 項目 | 要件 |
|------|------|
| テストカバレッジ | コア機能90%以上 |
| コード品質 | ESLint/Prettier準拠 |
| ドキュメント | API仕様書の維持 |
| ログ出力 | エラー発生時のログ記録 |

## 8. 制約事項

### 8.1 MVP段階の制約

| 制約 | 影響 | 対策 |
|------|------|------|
| 認証なし | デバイス間同期不可 | ローカルストレージで対応 |
| 外部API依存 | APIダウン時にデータ取得不可 | キャッシュ機能で緩和 |
| 日本語データなし | Tarkov.dev APIは英語のみ | 手動で日本語マッピング作成 |

### 8.2 前提条件

- モダンブラウザ（Chrome, Firefox, Safari, Edge最新版）
- JavaScript有効
- インターネット接続（初回データ取得時）
- ローカルストレージ使用可能

## 9. 受け入れ基準

### 9.1 機能テスト基準

| 機能 | 受け入れ基準 |
|------|-------------|
| タスク一覧表示 | 全トレーダーのタスクが正常に表示される |
| タスク完了チェック | チェックボックスで完了状態をトグルできる |
| 進捗ダッシュボード | 全体・トレーダー別進捗率が正しく計算・表示される |
| ローカルストレージ保存 | ブラウザ再起動後も進捗が保持される |
| フィルタリング | 条件に合致するタスクのみ表示される |

### 9.2 非機能テスト基準

| 項目 | 基準 |
|------|------|
| 初期表示速度 | 3秒以内に主要コンテンツが表示される |
| レスポンシブ | モバイル端末で正常に操作できる |
| エラー耐性 | API障害時にクラッシュしない |
| テストカバレッジ | コア機能90%以上 |

## 10. 用語定義

| 用語 | 定義 |
|------|------|
| タスク | ゲーム内でトレーダーから受注するクエスト |
| トレーダー | タスクを発行するNPC（Prapor, Therapist等） |
| 進捗率 | 完了タスク数 / 全タスク数 × 100 |
| FiR (Found in Raid) | レイド中に発見したアイテムのステータス |
| ローカルストレージ | ブラウザに保存されるクライアント側データ |
